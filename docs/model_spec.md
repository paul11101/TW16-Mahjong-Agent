# 台灣 16 張麻將策略模型規格


## Goal

本策略模組的目標，是根據台灣 16 張麻將中玩家可見的牌局資訊，
從目前所有合法動作中選擇一個動作。

模型只負責「決策」，不負責：
- 畫面辨識
- 台麻規則合法性判定
- 滑鼠點擊與自動操作

## Input

策略模組接收兩類輸入

### 1. GameState / Observation

只包含玩家可以得知的牌局資訊，例如：

- 自己的手牌
- 各玩家已打出的牌
- 公開的吃、碰、槓
- 公開花牌
- 目前輪到哪位玩家
- 自己的座位
- 剩餘牌數等公開資訊


### 2. LegalActions

由規則模組提供目前允許執行的合法動作。
策略只能從 LegalActions 中選擇動作。


策略不得使用：
- 對手的暗牌
- 未公開的牌山內容
- 其他玩家無法看到的隱藏資訊


## Output

策略模組輸出一個 Decision，表示本次選擇的動作。

Decision 至少包含：
- action：選擇的動作類型
- tile：動作所對應的牌，若沒有則為空
- score：此動作的評分
- reason：選擇此動作的原因


策略輸出的動作必須存在於 LegalActions 中


## Action Space

策略可能選擇的動作類型：

- discard：打出一張牌
- chi：吃牌
- pong：碰牌
- kong：槓牌
- win：胡牌
- pass：放棄目前可執行的反應動作

實際可選擇的動作由 LegalActions 提供，
策略不得自行產生不合法的動作。
