
# W5 Visible Features Requirements

## 1. 本週目標

在既有 555 維 Observation Encoder 基礎上，整理可見資訊特徵，為 Baseline v0.5 提供輸入。

Strategy 不直接讀取完整牌局的隱藏資訊。

## 2. 可使用的資訊

| 資訊 | 來源 | 可見性 |
|---|---|---|
| 自己的手牌 | Observation.hand | 自己可見 |
| 四位玩家河牌 | Observation.discards | 公開 |
| 四位玩家副露 | Observation.melds | 公開 |
| 四位玩家花牌 | Observation.flowers | 公開 |
| 當前玩家 | Observation.current_player | 公開狀態 |
| 自己座位 | Observation.seat | 自己可見 |
| 剩餘牌數 | Observation.remaining_tiles | 僅公開可取得時使用 |

## 3. 不可使用的資訊

- 其他玩家尚未公開的暗牌
- 未公開的牌牆內容及排列順序
- 未公開的未來摸牌結果
- 模擬器內部的隱藏狀態

## 4. 現有特徵格式

- 自己手牌：42 維
- 河牌：168 維
- 副露：168 維
- 花牌：168 維
- 當前玩家：4 維
- 自己座位：4 維
- 剩餘牌數：1 維

合計 555 維，維持原本 Encoder 相容性。

## 5. 資料限制

目前河牌、副露與花牌已經能編碼為牌 ID 數量，
但 Baseline 尚未充分利用這些資訊。

剩餘牌數若無法從實際畫面取得，必須使用 None，
不能直接讀取模擬器私有的牌牆資料。

目前 Observation.melds 只保存牌組內容，
尚未獨立保存每組副露的類型與來源，
後續若需要細分槓牌種類，須確認對接介面。

## 6. 後續安排

- D2：利用公開河牌建立統計特徵
- D3：加入副露、花牌、當前玩家及剩餘牌數的衍生特徵
- D4：預留危險度特徵，加入隱藏資訊隔離檢查
- D5：使用新的特徵更新 Baseline v0.5

## 7. Day 1 完成標準

- 整理既有 555 維特徵的位置與資料來源
- 確認可見資訊與隱藏資訊的界線
- 保持現有 Encoder 相容
- 完成特徵配置與隱藏資訊隔離測試
