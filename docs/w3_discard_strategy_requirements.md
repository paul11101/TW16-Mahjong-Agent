# W3 D1 基本出牌策略需求

## 目標

建立台灣 16 張麻將的基本出牌 Baseline v0。

策略只從 Rules 提供的合法 DISCARD 動作中選擇，
不允許自行產生非法動作。

## 輸入

- Strategy Observation
- LegalActions
- 自己的手牌
- 公開牌局資訊

## 出牌評估因素

Baseline v0 預計考慮：

1. 向聽數
   - 出牌後距離聽牌需要幾步

2. 有效進張
   - 出牌後有哪些牌可以改善牌型

3. 有效進張數量
   - 能改善牌型的剩餘牌張數

4. 基本牌效率
   - 優先保留較容易組成順子、刻子的牌

## 基本選擇原則

對每個合法 DISCARD：

1. 模擬打出該牌
2. 計算出牌後向聽數
3. 比較有效進張
4. 優先選擇：
   - 向聽數較小
   - 有效進張較多
5. 若仍相同，再使用固定規則決定

## 限制

Baseline v0 暫時只處理 DISCARD。

吃、碰、槓、胡、PASS
留到 W4 處理。

## 預計流程

LegalActions
→ 篩選 DISCARD
→ 模擬每個出牌結果
→ 計算牌效率特徵
→ 比較候選動作
→ Decision

## W3 後續

D2：實作向聽 / 牌效率特徵呼叫介面

D3：實作有效進張比較，完成出牌 Baseline v0

D4：建立固定牌型測試，Random vs Baseline

D5：整理錯誤牌型並調整
