## 2. 專案目標與範圍

- 建立「看懂畫面 → 理解牌局 → 選擇動作 → 完成操作 → 驗證結果」的自動對局系統。
- 第一版：可控的台麻測試介面；Agent **只讀玩家看得到的畫面**，連續完成 20 局，並留下可回放的決策與操作紀錄。
- 「1 局」＝一次發牌到胡牌或流局。不承諾職業級牌力；競技結果與操作可靠度分開評估。
- 假設：16 週、每人每週 8 小時；先支援 Windows、單一解析度、固定牌面風格。
- 層級：
  - 必做 MVP：台麻規則設定、可控遊戲畫面、辨識、規則型策略、滑鼠操作、開始/暫停/停止、紀錄回放。
  - 建議加值：小型台麻策略模型、策略比較儀表板、GPT 局後解說（可關閉，不進同步出牌流程）。
  - 後續擴充：外部目標遊戲適配、攝影機辨識實體牌。

## 3. 架構與模組契約

- 資料流：`Observation → GameState → LegalActions → Decision → ActionReceipt`
- 每一步都帶 `game_id`、`event_id`、時間戳、規則版本；Decision 含動作、候選分數與原因。
- 共同底座：事件紀錄（JSONL）、回放、規則版本、測試資料、操作狀態；SQLite 用於查詢實驗。
- 工具：Python 為主；擷取 MSS、辨識 OpenCV 模板比對、操作 PyAutoGUI、後端 FastAPI、資料 Pydantic、測試 pytest；測試介面/儀表板可用 TypeScript、HTML/CSS。
- Python 建議統一 3.11.x（64 位元）、使用 venv、鎖定套件版本。
- **每次操作後必須重新觀察；畫面未確認變化就不繼續下一個動作。**
- 測試後端的真實狀態只給評測器比對；最終端到端測試的 Agent 只讀可見畫面。
- 正式 Agent 只取得自己的手牌與公開資訊，未知牌保持未知；牌山、對手暗牌只給 evaluator 與訓練 oracle 分支。

## 4. 辨識與操作流程（企劃書 p.7）

| 步驟 | 重點 | 失敗時處理 |
|---|---|---|
| 擷取與定位 | 固定視窗與 DPI；擷取手牌、河牌、副露、花牌、分數、當前玩家、反應按鈕 | 視窗不在前景或區域偏移 → 停止操作並重定位 |
| 辨識與穩定化 | 模板比對、跨多幀確認；34 種基本牌，花牌另設類別 | 低信心、牌數異常、動畫未結束 → 重拍；必要時人工校正 |
| 狀態更新 | 依事件順序合併可見資訊（摸牌、吃碰槓、補花、換局），保留未知欄位 | 狀態不一致 → 暫停；由當前畫面與已確認事件重建 |
| 決策與映射 | 只從 LegalActions 選動作；牌實例映射到最新畫面位置；副露選牌另設步驟 | 狀態過期 → 重新決策；相同牌多位置仍用最新牌框 |
| 執行與確認 | PyAutoGUI 移動點擊；等待牌河/按鈕狀態變化；產生 ActionReceipt | 逾時先重觀察，不盲目重點；限制重試次數；提供立即停止 |

- 延遲預算（p95 ≤ 2 秒）：擷取與辨識 0.5 秒、狀態與策略 0.3 秒、操作與確認 1.2 秒。
- 標註截圖約 2,000 張，依完整場次切 70/15/15。
- 外部遊戲未選定：先交付可替換的介面適配器（座標、圖樣、事件、規則設定需重做）。

## 5. 策略與模型路線（與整合有關的部分）

- 主線：Agony5757/mahjong 的 VLOGMahjong（Apache-2.0）台麻化 → BC 預訓練 → 選做限額 DDQN/VLOG。不沿用日麻權重。
- 規則型 baseline 是備援與第一個教師；模型/GPT 失敗時仍須能用 baseline 完成對局。
- 工程閘門：W8 前完成規則、資料、BC 管線，環境不穩就暫停 RL；W12 DDQN/VLOG 未穩定優於 baseline 就以規則型 Agent 交付。
- 授權：mahjong16、Ting 授權未確認前不直接複製程式碼。

## 6. 驗收指標（企劃書 p.9）

| 指標 | 目標 |
|---|---|
| 規則正確性 | ≥100 個人工測例全過；再跑 10,000 局檢查牌數守恆與輪轉 |
| 辨識品質 | 牌實例正確率 ≥99%；整副手牌完全正確另報；關鍵狀態完整正確率 ≥95% |
| 合法行動 | 10,000 次保留決策中，實際送出的非法動作 = 0 |
| **操作可靠度（整合）** | **≥1,000 次實際 UI 動作，確認成功率 ≥99.5%；重複點擊 0 次；失敗/人工介入/重試都要記錄，不可從分母刪除** |
| **端到端與延遲（整合）** | **固定環境連續 20 局無需人工介入，重複 3 批；所有測試局無介入完成率 ≥95%；同步動作確認 p95 ≤ 2 秒** |
| 策略品質 | 固定對手池、相同牌山種子、座位輪換；先 1,000 局再 10,000 局；報平均淨得分、胡牌率、放槍率 |

- 比較：A 合法隨機、B 規則牌效率、C 台麻小型模型、D 可選 GPT。
- 升級條件：候選對 B 的平均淨得分更好，且以配對牌山/完整桌次估計的 95% 信賴區間下界 > 0。
- 測試機 CPU/RAM/GPU/解析度/版本都要記錄。
